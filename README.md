# Digi Witch (nazwa robocza)

Aplikacja Flutter (Android, iOS): numerologia z objaśnionymi obliczeniami, tarot (78 kart), biblioteka symboliki, archetypy i prywatny dziennik refleksji. Po polsku, offline, bez konta.

```
export PATH=$HOME/development/flutter/bin:$PATH
flutter test            # 45 testów
flutter run -d chrome   # podgląd
```

Dokumentacja: `docs/` — metoda (`numerology-method.md`), decyzje, testy, źródła treści, research (`docs/research/`: wymagania sklepów, konkurencja, prawa RWS).
